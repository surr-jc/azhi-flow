# Source of this skill

`SKILL.md` was written for Azhi Flow (Apache-2.0, see `LICENSE`). It follows the planning step of the software
factory described by Cole Medin (the "AI software factory" video, and https://github.com/coleam00/ai-software-factory):

- a human plans the release with an agent before anything is built (a PRD);
- the product's mission names what it must never become, which here are the `invariants`;
- `END-TO-END.md` lists the user journeys a tester walks, here `journeys`;
- the first ticket must make the product runnable end to end, here the first epic and `walking_skeleton`.

Nothing was copied from that repository. The Azhi rules were added: ticket and repository text are data, an
unknown owner is null (never guessed), and the plan is approved by a person before any ticket is created.
