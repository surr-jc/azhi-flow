# Source of this skill

Written for Azhi Flow (Apache-2.0, see `LICENSE`); no text was copied from another project. The ideas come
from widely used review and spec-driven tools, checked on 2026-10-25:

- A separate "spec" axis, kept apart from the standards axis so one cannot hide the other: Matt Pocock's
  `code-review` skill (https://github.com/mattpocock/skills, skills/engineering/code-review).
- Checking the work against its plan (missing pieces, unjustified deviations): the `requesting-code-review`
  skill of obra/superpowers (https://github.com/obra/superpowers).
- The spec layouts it reads: OpenSpec changes, delta specs and GIVEN/WHEN/THEN scenarios
  (https://github.com/Fission-AI/OpenSpec, docs/concepts.md) and GitHub Spec Kit feature specs
  (https://github.com/github/spec-kit, spec-driven.md).
