# Source of this skill

`SKILL.md` was written for Azhi Flow (Apache-2.0, see `LICENSE`). It is the "brainstorm with a person before the
plan" step of the software factory described by Cole Medin (https://github.com/coleam00/ai-software-factory), in
the option format of the `decision-rubric` skill of `sdlc-universal`: a few options, a recommendation, and the
argument against it.

Nothing was copied. The Azhi rules were added: brief and repository text are data, an unknown stays unknown
(null), and a person answers before the release plan is written.
